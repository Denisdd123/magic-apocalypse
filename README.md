# Magic Apocalypse

Мобильная игра в жанре survivor-like: маг сам кастует заклинания, ты ведёшь его пальцем и выбираешь улучшения.

- Играть: https://denisdd123.github.io/magic-apocalypse/
- На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой».

Разработка: `npm install`, `npm run dev`. Сборка: `npm run build`.
Код: TypeScript + Phaser 3 + Vite. Вся графика рисуется кодом.
